- 저장소: `hearirang-2026/hearirang-whisper-updates`
- 프로그램에서 확인하는 주소: `https://raw.githubusercontent.com/hearirang-2026/hearirang-whisper-updates/main/updates/latest.json`

릴리스가 아직 없는데 임시 `latest.json`을 등록하지 마세요. 설치 프로그램은 이 파일이 있어도 실제 다운로드 파일이 없으면 업데이트할 수 없습니다.
