# Hearirang Whisper — 다운로드 및 업데이트

Windows에서 음성·노래·강의 내용을 인식하고 자막을 만드는 **Hearirang Whisper Subtitle Studio**의 공식 설치파일 배포 저장소입니다.

> AI와 함께 개인적인 필요에 따라 만든 프로그램입니다. 필요한 분들과 나누기 위해 설치파일을 공개합니다. 개선·정기 업데이트나 개별 기술 지원을 약속하지 않습니다.

## 설치파일 다운로드

1. [Releases(배포 목록)](https://github.com/hearirang-2026/hearirang-whisper-updates/releases)로 이동합니다.
2. 등록된 최신 배포의 **Assets**에서 `Hearirang_Whisper_Setup_x64.exe`를 클릭합니다.
3. 다운로드한 파일을 실행하고 설치 안내에 따릅니다.

**Windows 64비트용 설치파일**입니다. 등록된 Release가 없으면 아직 다운로드할 배포판이 없는 상태입니다.

## 기존 프로그램에서 업데이트하기

Hearirang Whisper **V1.2 이상**의 업데이트 화면은 이 저장소의 GitHub 배포 정보를 기본적으로 확인하도록 설계되었습니다. GitHub에 실제 설치파일과 업데이트 정보가 **모두 게시된 뒤에만** 새 버전이 표시됩니다.

업데이트 전 필요하면 자막·가사·대본 등 현재 작업 내용을 저장해 주세요. 설치를 계속하면 실행 중인 프로그램이 종료될 수 있습니다. 모델과 개인 설정은 설치 때 지우지 않도록 설계되었습니다.

자세한 사용 순서는 [한국어 설치 안내](guides/INSTALL_KO.md)에서 확인할 수 있습니다.
