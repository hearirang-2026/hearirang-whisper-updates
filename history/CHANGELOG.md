# 변경 이력

## V1.3.0 — GitHub 공개 배포 시험 (2026-10-29)

- **기능 개선 없음.** V1.2의 음성 인식·자막·번역·사용자 인터페이스를 그대로 유지합니다.
- 프로그램·설치파일·업데이트 정보의 버전 표기를 **1.3.0**으로 올렸습니다.
- GitHub 공개 Release에서 설치파일 다운로드 및 V1.2 → V1.3 프로그램 내부 업데이트 경로를 검증하는 배포 시험입니다.
- Windows 설치판은 기존 업데이트 도우미와 설치 전 종료 동의 안내를 유지합니다.
- 설치파일은 미서명 베타입니다.

## V1.2.0 — GitHub 업데이트 준비 (2026-10-29)

- GitHub 공개 배포 경로 및 단계별 업데이트 확인 기능 준비.
- Windows 설치 첫 화면에 종료 및 미저장 작업 안내와 종료 동의 체크 반영.
- 기존 Large-v3 음성 인식 엔진 및 사용자 데이터 보호 설계 유지.

## V1.1 — 설치·종료 안정성

- 종료 후 설치가 시작되도록 Windows 업데이트 도우미 개선.
- 기존 인식 기능 유지.

**유의:** 이 문서는 공개 배포의 주요 이력 요약입니다. 실제 내려받을 수 있는 버전은 [GitHub Releases](https://github.com/hearirang-2026/hearirang-whisper-updates/releases)에 게시된 파일을 기준으로 합니다.
