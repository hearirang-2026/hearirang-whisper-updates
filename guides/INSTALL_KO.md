# Hearirang Whisper — Windows 설치 및 업데이트 안내

## 처음 설치하는 경우

1. [GitHub Releases](https://github.com/hearirang-2026/hearirang-whisper-updates/releases)에서 게시된 최신 배포를 엽니다.
2. **Assets** 항목의 `Hearirang_Whisper_Setup_x64.exe`를 다운로드합니다.
3. 실행 중인 Hearirang Whisper가 있다면 작업 내용을 확인합니다. 필요한 자막·원가사·대본은 먼저 저장합니다.
4. 설치 EXE를 실행하고 첫 화면의 종료 안내를 읽습니다.
5. 동의할 경우 **「프로그램 종료에 동의합니다.」** 를 체크하고 설치를 계속합니다.
6. 설치 후 Hearirang Whisper를 실행합니다.

**지원 대상:** Windows 64비트 PC. 다른 운영체제에서의 설치는 이 Windows EXE로 지원하지 않습니다.

## V1.2에서 V1.3으로 업데이트하는 경우

이 배포의 목적은 **GitHub 공개 다운로드 및 프로그램 내부 자동 업데이트 경로 검증**입니다. V1.3은 V1.2의 기능을 변경하지 않고 버전만 올린 시험판입니다.

1. 설치된 **V1.2를 그대로 유지**합니다.
2. V1.3 Release의 EXE와 `updates/latest.json`이 모두 공개된 것을 확인합니다.
3. V1.2에서 **업데이트 → 지금 확인**을 누릅니다.
4. V1.3이 표시되면 **다운로드 및 검증 → 설치 시작** 순서로 진행합니다.
5. 필요할 때만 작업 내용을 저장하고, 종료 안내에 동의하여 설치합니다.
6. 재실행한 뒤 **현재 버전 1.3.0** 및 기존 음성 인식 모델·설정 유지 여부를 확인합니다.

업데이트 결과가 예상과 다르면 설치를 계속하기 전에 현재 화면을 확인하세요. 사용자 설정에 따라 이전 Google Drive/직접 지정 업데이트 주소가 선택되어 있을 수 있습니다.

## 음성 인식 모델과 기존 설정

- **Large-v3 등 음성 인식 모델은 설치 EXE에 포함되어 있지 않습니다.** 필요한 모델은 프로그램에서 사용자가 선택하여 다운로드합니다.
- 설치 파일은 기존 모델, API 키, 자막 및 사용자 설정을 삭제하지 않는 방향으로 구성했습니다.
- **미저장 작업**은 프로그램 종료 과정에서 사라질 수 있습니다. 저장할 작업이 있다면 먼저 저장하세요.
- 신규 설치·모델 다운로드·음성 인식은 사용 중인 PC 환경 및 네트워크 상태의 영향을 받습니다.

## Windows 보안 안내

- 이 프로그램은 개인 제작 **미서명 베타 설치파일**입니다. Windows에서 신뢰도나 게시자 관련 경고를 표시할 수 있습니다.
- 경고가 나오면 다운로드 출처를 확인하고 사용자 스스로 실행 여부를 결정하세요.
- Windows 보안 기능을 끄거나 경고를 우회할 필요는 없습니다.
